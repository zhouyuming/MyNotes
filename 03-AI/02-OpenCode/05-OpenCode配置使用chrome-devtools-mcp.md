# 开启指令

```
powershell -Command "Start-Process 'C:\Program Files\Google\Chrome\Application\chrome.exe' -ArgumentList '--remote-debugging-port=9222','--no-first-run','--no-default-browser-check','--user-data-dir=C:\temp-chrome-debug'"
```
