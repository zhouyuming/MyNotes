# UDS简介

UDS是Unified Diagnostic Services，统一诊断服务，是汽车电子中常用的诊断协议。

UDS是ISO 14229定义的汽车诊断协议，用于ECU软件刷写、故障诊断、数据读写等。

| SID         | 服务        | 说明                           |
| ----------- | ----------- | ------------------------------ |
| 0x10        | 诊断会话控制 | 进入不同会话（默认/扩展/编程）    |
| 0x11        | ECU复位     | 硬复位/软复位                    |
| 0x22        | 按ID读取数据 | 读取DID数据                     |
| 0x2E        | 按ID写入数据 | 写入DID数据                     |
| 0x19        | 读取DTC      | 故障码读取                      |
| 0x14        | 清除DTC      | 清除故障码                      |
| 0x27        | 安全访问	     | 解锁受限服务                    |
| 0x34        | 请求下载	     | 开始刷写                        |
| 0x36        | 传输数据	     | 传输数据块                      |
| 0x37        | 请求传输退出  | 结束刷写                        |	

## UDS协议标准

UDS（UnifiedDiagnostic Services，统一诊断服务,有时也称增强诊断）是ISO-14229定义的基于OSI模型中应用层的协议。其中，ISO 14229-1定义了诊断服务，但不涉及网络层及实现手段，只有应用层的内容，因此可在不同的汽车总线（如CAN, LIN, Flexray, Ethernet和K-line等）上实现
